Python Functions

ধরো একটা program-এ পাঁচ জায়গায় ছাত্রের গড় মার্কস বের করতে হবে। পাঁচবার একই কোড লিখবে? আর পরে হিসাবে ভুল পেলে পাঁচ জায়গাতেই ঠিক করবে? Programming-এ এই সমস্যার সমাধান হলো function — একটা কাজের কোড একবার লিখে একটা নাম দিয়ে রাখা, তারপর যতবার দরকার নাম ধরে ডাকা।

এই অধ্যায়ে দেখব function কী, Python-এর তৈরি করা function আর নিজের বানানো function-এর পার্থক্য, function কীভাবে ডাকতে হয়, argument কত রকম, function-এ data পাঠালে আসলে কী ঘটে, আর তারিখ-সময় নিয়ে কাজ করার function। শেষে পূর্ণ কয়েকটা program লিখব।

1.1 Function কী?

সংজ্ঞা (পরীক্ষার জন্য)

Function হলো একটি নির্দিষ্ট কাজ সম্পাদনের জন্য লেখা কতগুলো statement-এর একটি নামযুক্ত block। Function একবার তৈরি (define) করে program-এর যেকোনো জায়গা থেকে যতবার ইচ্ছা নাম ধরে ডাকা (call) যায়। Function বাইরে থেকে data (argument) নিতে পারে এবং কাজ শেষে ফলাফল (return value) ফেরত দিতে পারে।

বাস্তব উদাহরণ

রাইস কুকারের কথা ভাবো। তুমি চাল আর পানি দাও (input), সুইচ চাপো, কিছুক্ষণ পর ভাত পাও (output)। ভেতরে কী হচ্ছে প্রতিবার তোমাকে ভাবতে হয় না। একবার কেনা রাইস কুকার প্রতিদিন ব্যবহার করা যায়। Function ঠিক এরকম: একবার লেখো, ভেতরের কাজ লুকানো থাকে, বারবার ব্যবহার করো।

Function কেন দরকার?

  • কোড পুনর্ব্যবহার (Reusability): একবার লিখে বহুবার ব্যবহার।
  • সহজে পড়া যায় (Readability): বড় program ছোট ছোট নামযুক্ত অংশে ভাগ হয়, নাম দেখেই কাজ বোঝা যায়।
  • সহজে ভুল ধরা যায় (Debugging): ভুল থাকলে শুধু সেই function পরীক্ষা করলেই চলে।
  • রক্ষণাবেক্ষণ সহজ (Maintenance): নিয়ম বদলালে এক জায়গায় বদলালেই সবখানে বদলে যায়।

1.3 Function ডাকার পদ্ধতি

বাংলাএই টপিকের ভিডিও · নভেম্বর ২০২৩

Day-30🐍 60 Days of Python | More about Return in Function | Python Bangla Tutorials |@aiquest

STUDY MART · YouTube-এ দেখো ↗

Function তৈরি করলেই সেটা চলে না — ডাকতে (call) হয়। Function call করার ধাপগুলো:

  1. আগে define করো: Python উপর থেকে নিচে চলে, তাই call-এর আগে def লেখা থাকতে হবে।
  2. নাম লিখে bracket দাও: function_name()। Bracket ছাড়া শুধু নাম লিখলে function চলে না।
  3. Argument পাঠাও: parameter যতগুলো, সাধারণত ততগুলো মান পাঠাতে হয়, সঠিক ক্রমে।
  4. Return মান গ্রহণ করো: function কিছু return করলে সেটা variable-এ রাখো বা সরাসরি ব্যবহার করো।

Function call হলে program-এর নিয়ন্ত্রণ (control) লাফ দিয়ে function-এর ভেতরে চলে যায়, body চালায়, তারপর যেখান থেকে ডাকা হয়েছিল ঠিক সেখানে ফিরে আসে। নিচের উদাহরণে print দিয়ে এই লাফটা দেখা যাবে।

উদাহরণ 1.3Control কোথায় যায়, দেখা

সমস্যা: একটা function আরেকটা function ডাকছে — print দিয়ে চলার ক্রম দেখাও।

লাইন-বাই-লাইন ব্যাখ্যা
15
print("Program start")
Program এখান থেকে শুরু। উপরের দুটো def শুধু function তৈরি করেছে, চালায়নি।
16

show_result ডাকা হলো → control চলে গেল লাইন 10-এ।

show_result নিজেই get_grade ডাকল → control গেল লাইন 2-এ। 72 >= 80 মিথ্যা, 72 >= 60 সত্য, তাই "A" return।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • Python-এ function call করার পদ্ধতি বর্ণনা করো। (3-4 নম্বর)

ধাপগুলো ক্রমানুসারে লেখো, তারপর একটা ছোট program দিয়ে দেখাও control কীভাবে function-এ যায় আর ফিরে আসে।

1.4 Pass by Value বনাম Pass by Reference

বাংলাএই টপিকের ভিডিও · নভেম্বর ২০২৪

Mutable and Immutable Data Types in Python | Python in Bangla | Lecture-18

AlgoBangla29 · YouTube-এ দেখো ↗

Function-এ argument পাঠালে আসলে কী যায় — মানটার একটা কপি, নাকি আসল data-র ঠিকানা? Programming ভাষাভেদে এর দুটো প্রচলিত পদ্ধতি আছে:

  • Pass by Value: argument-এর মানের একটা কপি function-এ যায়। Function-এর ভেতরে কপি বদলালে বাইরের আসল variable বদলায় না। (C ভাষার সাধারণ পদ্ধতি)
  • Pass by Reference: argument-এর ঠিকানা (reference) function-এ যায়। Function-এর ভেতরে বদলালে বাইরের আসল data-ও বদলে যায়।

বাস্তব উদাহরণ

Pass by value হলো নোটের ফটোকপি দেওয়া — বন্ধু ফটোকপিতে যত খুশি দাগ দিক, তোমার আসল নোট অক্ষত। Pass by reference হলো Google Drive-এর একটা document-এর লিংক শেয়ার করা — বন্ধু ওই লিংকে গিয়ে কিছু বদলালে তোমার document-ও বদলে যায়, কারণ দুজনেই একই document দেখছ।

Python কোনটা ব্যবহার করে? সঠিক উত্তর হলো: কোনোটাই হুবহু না। Python ব্যবহার করে pass by object reference (একে pass by assignment-ও বলে) — function-এ সবসময় object-এর reference যায়। কিন্তু ফল কেমন দেখাবে সেটা নির্ভর করে object-টা বদলানো যায় কিনা তার উপর:

Object-এর ধরনউদাহরণFunction-এর ভেতরে বদলালেদেখতে কার মতো
Immutable (বদলানো যায় না)int, float, str, tupleনতুন object তৈরি হয়, বাইরেরটা অক্ষতPass by value
Mutable (বদলানো যায়)list, dict, setএকই object বদলায়, বাইরেও দেখা যায়Pass by reference

Function ডাকার সময় যে মান পাঠানো হয় সেটা argument, আর function তৈরির সময় bracket-এ যে নাম লেখা হয় সেটা parameter। Python-এ argument পাঠানোর পাঁচটা উপায় আছে:

ধরনকীভাবেউদাহরণ
Positionalক্রম অনুযায়ী মান বসেinfo("Rahim", 101)
Keywordparameter-এর নাম ধরে মান দেওয়া; ক্রম লাগে নাinfo(roll=101, name="Rahim")
Defaultমান না দিলে আগে থেকে ঠিক করা মান বসেdef info(name, dept="CST")
Variable-length (*args)যত খুশি positional argument, tuple হিসেবে আসেdef total(*marks)
Keyword variable-length (**kwargs)যত খুশি নামসহ argument, dictionary হিসেবে আসেdef profile(**details)

উদাহরণ 1.6Positional, Keyword ও Default Argument

সমস্যা: ছাত্রের তথ্য দেখানোর function তিনভাবে ডাকো।

লাইন-বাই-লাইন ব্যাখ্যা
1
def student_info(name, roll, dept="CST", semester=1):
name আর roll বাধ্যতামূলক; dept আর semester-এর default মান আছে। নিয়ম: default মানওয়ালা parameter সবসময় বাধ্যতামূলকগুলোর পরে বসে।
4
student_info("Rahim", 101)
শুধু দুটো positional argument — বাকি দুটো default মান নিল।
5
student_info("Sumaiya", 102, "Civil", 4)
চারটাই positional, ক্রম অনুযায়ী বসল।
6

Keyword argument — নাম ধরে দেওয়ায় ক্রম উল্টো হলেও সমস্যা নেই। dept দেওয়া হয়নি, তাই default "CST"।

উদাহরণ 1.7*args ও **kwargs

সমস্যা: যত খুশি বিষয়ের মার্কস নিয়ে মোট ও গড় বের করো, আর যত খুশি তথ্য দিয়ে একটা প্রোফাইল দেখাও।

লাইন-বাই-লাইন ব্যাখ্যা

    print("Received:", marks)
*marks যত খুশি argument একটা tuple-এ জমা করে। tuple হলো গোল bracket-এর list, যেটা বদলানো যায় না।
3
    return sum(marks), sum(marks) / len(marks)
দুটো মান একসাথে return — Python এগুলোকে একটা tuple বানিয়ে ফেরত দেয়।
10

ফেরত আসা দুটো মান দুটো variable-এ ভাগ হয়ে গেল।

মনে রাখো

Parameter-এর ক্রমের নিয়ম মনে রাখো: সাধারণ → default → *args → **kwargs। যেমন: def f(a, b=2, *args, **kwargs)। আর ডাকার সময় positional argument সবসময় keyword argument-এর আগে।

সাধারণ ভুল

ভুল

ফল: SyntaxError: positional argument follows keyword argument

সঠিক

ভুল

ফল: SyntaxError: parameter without a default follows parameter with a default

সঠিক

Default মানওয়ালা parameter-এর পরে default ছাড়া parameter বসানো যায় না।

Function-এর program লেখার প্রশ্নে প্রতিটা আলাদা কাজের জন্য আলাদা function বানাও, নাম এমন দাও যেন দেখেই কাজ বোঝা যায়, আর ফলাফল print না করে return করাও — শেষে output লিখতে ভুলো না।

অনুশীলন

is_prime(n) function লেখো (n মৌলিক হলে True), তারপর আরেকটা function primes_upto(limit) লেখো যেটা is_prime() ব্যবহার করে limit পর্যন্ত সব মৌলিক সংখ্যার list return করবে।

অধ্যায়ের সারসংক্ষেপ

বিষয়মূল কথা
Functionনির্দিষ্ট কাজের নামযুক্ত কোড block; def দিয়ে তৈরি, নাম() দিয়ে ডাকা হয়; return না থাকলে None।
Library বনাম User-definedLibrary: Python-এর তৈরি (print, len, math.sqrt); User-defined: def দিয়ে নিজের বানানো।
Function callআগে define; নাম + bracket + argument; control function-এ গিয়ে আবার ফিরে আসে।
Value বনাম ReferencePython: pass by object reference; immutable-এ value-এর মতো, mutable-এ reference-এর মতো আচরণ।
ArgumentPositional, keyword, default, *args (tuple), **kwargs (dictionary)।
Date ও Timedatetime.now(), date.today(), timedelta, strftime(); time.time(), time.sleep()।

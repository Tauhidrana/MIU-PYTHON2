Python Functions

ধরো একটা program-এ পাঁচ জায়গায় ছাত্রের গড় মার্কস বের করতে হবে। পাঁচবার একই কোড লিখবে? আর পরে হিসাবে ভুল পেলে পাঁচ জায়গাতেই ঠিক করবে? Programming-এ এই সমস্যার সমাধান হলো function — একটা কাজের কোড একবার লিখে একটা নাম দিয়ে রাখা, তারপর যতবার দরকার নাম ধরে ডাকা।

এই অধ্যায়ে দেখব function কী, Python-এর তৈরি করা function আর নিজের বানানো function-এর পার্থক্য, function কীভাবে ডাকতে হয়, argument কত রকম, function-এ data পাঠালে আসলে কী ঘটে, আর তারিখ-সময় নিয়ে কাজ করার function। শেষে পূর্ণ কয়েকটা program লিখব।

সংজ্ঞা (পরীক্ষার জন্য)

Function হলো একটি নির্দিষ্ট কাজ সম্পাদনের জন্য লেখা কতগুলো statement-এর একটি নামযুক্ত block। Function একবার তৈরি (define) করে program-এর যেকোনো জায়গা থেকে যতবার ইচ্ছা নাম ধরে ডাকা (call) যায়। Function বাইরে থেকে data (argument) নিতে পারে এবং কাজ শেষে ফলাফল (return value) ফেরত দিতে পারে।

বাস্তব উদাহরণ

রাইস কুকারের কথা ভাবো। তুমি চাল আর পানি দাও (input), সুইচ চাপো, কিছুক্ষণ পর ভাত পাও (output)। ভেতরে কী হচ্ছে প্রতিবার তোমাকে ভাবতে হয় না। একবার কেনা রাইস কুকার প্রতিদিন ব্যবহার করা যায়। Function ঠিক এরকম: একবার লেখো, ভেতরের কাজ লুকানো থাকে, বারবার ব্যবহার করো।

Function কেন দরকার?

  • কোড পুনর্ব্যবহার (Reusability): একবার লিখে বহুবার ব্যবহার।
  • সহজে পড়া যায় (Readability): বড় program ছোট ছোট নামযুক্ত অংশে ভাগ হয়, নাম দেখেই কাজ বোঝা যায়।
  • সহজে ভুল ধরা যায় (Debugging): ভুল থাকলে শুধু সেই function পরীক্ষা করলেই চলে।
  • রক্ষণাবেক্ষণ সহজ (Maintenance): নিয়ম বদলালে এক জায়গায় বদলালেই সবখানে বদলে যায়।

1.3 Function ডাকার পদ্ধতি

বাংলাএই টপিকের ভিডিও · নভেম্বর ২০২৩

Function তৈরি করলেই সেটা চলে না — ডাকতে (call) হয়। Function call করার ধাপগুলো:

  1. আগে define করো: Python উপর থেকে নিচে চলে, তাই call-এর আগে def লেখা থাকতে হবে।
  2. নাম লিখে bracket দাও: function_name()। Bracket ছাড়া শুধু নাম লিখলে function চলে না।
  3. Argument পাঠাও: parameter যতগুলো, সাধারণত ততগুলো মান পাঠাতে হয়, সঠিক ক্রমে।
  4. Return মান গ্রহণ করো: function কিছু return করলে সেটা variable-এ রাখো বা সরাসরি ব্যবহার করো।

Function call হলে program-এর নিয়ন্ত্রণ (control) লাফ দিয়ে function-এর ভেতরে চলে যায়, body চালায়, তারপর যেখান থেকে ডাকা হয়েছিল ঠিক সেখানে ফিরে আসে। নিচের উদাহরণে print দিয়ে এই লাফটা দেখা যাবে।

1.4 Pass by Value বনাম Pass by Reference

বাংলাএই টপিকের ভিডিও · নভেম্বর ২০২৪

Mutable and Immutable Data Types in Python | Python in Bangla | Lecture-18

AlgoBangla29 · YouTube-এ দেখো ↗

Function-এ argument পাঠালে আসলে কী যায় — মানটার একটা কপি, নাকি আসল data-র ঠিকানা? Programming ভাষাভেদে এর দুটো প্রচলিত পদ্ধতি আছে:

  • Pass by Value: argument-এর মানের একটা কপি function-এ যায়। Function-এর ভেতরে কপি বদলালে বাইরের আসল variable বদলায় না। (C ভাষার সাধারণ পদ্ধতি)
  • Pass by Reference: argument-এর ঠিকানা (reference) function-এ যায়। Function-এর ভেতরে বদলালে বাইরের আসল data-ও বদলে যায়।

বাস্তব উদাহরণ

Pass by value হলো নোটের ফটোকপি দেওয়া — বন্ধু ফটোকপিতে যত খুশি দাগ দিক, তোমার আসল নোট অক্ষত। Pass by reference হলো Google Drive-এর একটা document-এর লিংক শেয়ার করা — বন্ধু ওই লিংকে গিয়ে কিছু বদলালে তোমার document-ও বদলে যায়, কারণ দুজনেই একই document দেখছ।

Python কোনটা ব্যবহার করে? সঠিক উত্তর হলো: কোনোটাই হুবহু না। Python ব্যবহার করে pass by object reference (একে pass by assignment-ও বলে) — function-এ সবসময় object-এর reference যায়। কিন্তু ফল কেমন দেখাবে সেটা নির্ভর করে object-টা বদলানো যায় কিনা তার উপর:

Object-এর ধরনউদাহরণFunction-এর ভেতরে বদলালেদেখতে কার মতো
Immutable (বদলানো যায় না)int, float, str, tupleনতুন object তৈরি হয়, বাইরেরটা অক্ষতPass by value
Mutable (বদলানো যায়)list, dict, setএকই object বদলায়, বাইরেও দেখা যায়Pass by reference

Passing by Reference কী? (Pass by Value ও Pass by Reference সংক্ষেপে লেখ।)

উত্তর

Pass by Value: function-এ argument-এর মানের একটি কপি পাঠানো হয়। function-এর ভেতরে মান বদলালে বাইরের মূল variable বদলায় না।

Pass by Reference: function-এ argument-এর মানের বদলে তার ঠিকানা (reference) পাঠানো হয়। ফলে function-এর ভেতরে পরিবর্তন করলে বাইরের মূল data-ও বদলে যায়।

Python-এ: Python "pass by object reference" পদ্ধতি ব্যবহার করে। int, float, str-এর মতো immutable object পাঠালে আচরণ pass by value-এর মতো, আর list, dict-এর মতো mutable object পাঠিয়ে ভেতরে বদলালে আচরণ pass by reference-এর মতো হয়।

সুবিধা:

  • জটিল সমস্যা (factorial, Fibonacci, tree) অল্প ও সুন্দর কোডে লেখা যায়।
  • গাণিতিক সংজ্ঞার সাথে কোড হুবহু মিলে যায়, তাই বোঝা সহজ।
  • বড় সমস্যাকে একই ধরনের ছোট সমস্যায় ভাগ করা যায়।

অসুবিধা:

  • প্রতিটি call memory (stack)-এ জায়গা নেয়, তাই loop-এর চেয়ে বেশি memory লাগে ও ধীরে চলে।
  • base case না থাকলে বা ভুল হলে অসীম call হয়ে RecursionError দেখায়।
  • নতুনদের জন্য বোঝা ও ভুল খোঁজা কঠিন।

উত্তর

Python-এ function-এ argument পাঠানোর প্রধান পদ্ধতি:

  • Positional (Required) Argument: ক্রম অনুযায়ী মান parameter-এ বসে; সংখ্যা ও ক্রম মিলতে হয়।
  • Keyword Argument: parameter-এর নাম ধরে মান দেওয়া হয়, তাই ক্রম লাগে না।
  • Default Argument: মান না দিলে আগে থেকে ঠিক করা মান বসে।
  • **Variable-length Argument (*args):** যত খুশি positional argument নেওয়া যায়; tuple হিসেবে আসে।
  • Keyword Variable-length Argument (kwargs):** যত খুশি নামসহ argument; dictionary হিসেবে আসে।

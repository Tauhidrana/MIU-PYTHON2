Module, Package and Application Software

Program বড় হতে থাকলে একটা file-এ সব কোড রাখা অসম্ভব হয়ে যায় — হাজার লাইনের একটা file-এ কোনো function খুঁজে পাওয়াই কঠিন। সমাধান হলো কোডকে আলাদা আলাদা file-এ (module) ভাগ করা, আর সম্পর্কিত module-গুলো একটা folder-এ (package) সাজানো। এভাবেই বাস্তবের বড় software তৈরি হয়।

এই অধ্যায়ের শুরুতে দেখব application software কী, কত প্রকার আর কোথায় ব্যবহার হয়। তারপর module ও package-এর ধারণা, এদের গুরুত্ব, আর নিজের হাতে module ও package তৈরি করব।

3.1 Application Software কী?

কম্পিউটারের software মোটা দাগে দুই ধরনের। System software কম্পিউটার চালায় — operating system (Windows, Linux, Android), device driver, utility program। আর application software দিয়ে ব্যবহারকারী নিজের নির্দিষ্ট কাজ করে — চিঠি লেখা, হিসাব রাখা, ছবি সম্পাদনা, ভিডিও দেখা।

সংজ্ঞা (পরীক্ষার জন্য)

Application software হলো এমন software, যা ব্যবহারকারীর নির্দিষ্ট কোনো কাজ বা সমস্যা সমাধানের জন্য তৈরি করা হয়। এটি system software-এর (operating system) উপর চলে এবং সরাসরি ব্যবহারকারীর প্রয়োজন মেটায়। যেমন: Microsoft Word, Excel, web browser, accounting software।

বাস্তব উদাহরণ

একটা বাড়ির কথা ভাবো। বিদ্যুৎ সংযোগ, পানির লাইন, দেয়াল — এগুলো ছাড়া বাড়ি চলে না, কিন্তু এগুলো নিয়ে তুমি সরাসরি কাজ করো না: এরা system software। আর টিভি, ফ্রিজ, রাইস কুকার — এগুলো দিয়ে তুমি নিজের কাজ করো, এবং এরা চলে বিদ্যুৎ সংযোগের উপর: এরা application software।

  • General Purpose Application Software: অনেক ধরনের ব্যবহারকারী অনেক ধরনের কাজে ব্যবহার করে। বাজারে তৈরি অবস্থায় পাওয়া যায়।

সংজ্ঞা (পরীক্ষার জন্য)

Module হলো Python কোড ধারণকারী একটি .py file, যার ভেতরে function, class ও variable থাকে এবং যা অন্য program-এ import করে ব্যবহার করা যায়। যেমন: math, random, datetime বা নিজের তৈরি geometry.py।

Package হলো সম্পর্কিত module-গুলোর একটি folder (directory), যার ভেতরে সাধারণত __init__.py নামে একটি বিশেষ file থাকে। Package দিয়ে অনেকগুলো module সুশৃঙ্খলভাবে সাজানো হয়।

বাস্তব উদাহরণ

একটা লাইব্রেরির কথা ভাবো। প্রতিটা বই একটা module — একটা নির্দিষ্ট বিষয়ে লেখা। একই বিষয়ের বইগুলো একটা তাকে (shelf) রাখা: সেই তাকটা একটা package। আর পুরো লাইব্রেরি হলো library — অনেকগুলো package-এর সংগ্রহ।

বিষয়ModulePackageLibrary
কীএকটা .py filemodule-এর folderpackage/module-এর বড় সংগ্রহ
চেনার উপায়.py extensionfolder + __init__.pyসাধারণত pip দিয়ে install
উদাহরণmath, random, geometry.pyschool/, os, emailNumPy, Django, pandas

3.5 Module ও Package-এর গুরুত্ব

  1. কোড পুনর্ব্যবহার (Reusability): একবার লেখা module যেকোনো program-এ import করে ব্যবহার করা যায় — একই function বারবার লিখতে হয় না।
  2. সুশৃঙ্খল কাঠামো (Organization): বড় program যুক্তিসঙ্গত ছোট ছোট file আর folder-এ ভাগ হয়, ফলে কোড খুঁজে পাওয়া ও বোঝা সহজ।
  3. নামের সংঘর্ষ এড়ানো (Namespace): দুটো module-এ একই নামের function থাকলেও সমস্যা নেই — student.show() আর teacher.show() আলাদা।
  4. সহজ রক্ষণাবেক্ষণ (Maintenance): ভুল ঠিক করতে বা নিয়ম বদলাতে শুধু সংশ্লিষ্ট module-এ হাত দিলেই হয়।
  5. দলগত কাজ (Team Work): একেকজন programmer একেকটা module-এ কাজ করতে পারে।
  6. শেয়ার করা সহজ: package বানিয়ে অন্যদের দেওয়া যায়। হাজার হাজার package pip install দিয়ে বিনামূল্যে পাওয়া যায় — Python-এর জনপ্রিয়তার একটা বড় কারণ এটাই।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • Module ও package-এর গুরুত্ব বর্ণনা করো। (4 নম্বর)

প্রতিটা পয়েন্টের শিরোনাম আর এক-দুই লাইনের ব্যাখ্যা লেখো; সাথে একটা ছোট import উদাহরণ দিলে ভালো।

Module তৈরির ধাপ: (১) প্রয়োজনীয় function একটি .py file-এ লিখে নির্দিষ্ট নামে save করো — এটাই module। (২) একই folder-এ আরেকটি file থেকে import module_name লিখে module ব্যবহার করো। (৩) module-এর function ডাকতে module_name.function_name() লেখো।

লাইন-বাই-লাইন ব্যাখ্যা
1
"""fibo.py - Fibonacci helper functions"""
docstring দিয়ে module-এর বর্ণনা। file-টি fibo.py নামে save করতে হবে।
3–10
def fib_series(n):
    """Return the first n Fibonacci numbers as a list."""
    series = []
    a, b = 0, 1
    for _ in range(n):
        series.append(a)
        a, b = b, a + b
    return series
fib_series(): প্রথম দুটি পদ 0 ও 1; প্রতিবার আগের দুই পদ যোগ করে পরের পদ তৈরি করে list-এ রাখে।
12–14
def fib_sum(n):
    """Return the sum of the first n Fibonacci numbers."""
    return sum(fib_series(n))
fib_sum(): একই module-এর fib_series() ব্যবহার করে যোগফল দেয়।
লাইন-বাই-লাইন ব্যাখ্যা
1
import fibo
fibo module import — .py লিখতে হয় না। দুটি file একই folder-এ থাকতে হবে।
2
from fibo import fib_sum
নির্দিষ্ট function সরাসরি import।
5–6
print("Fibonacci series:", fibo.fib_series(n))
print("Sum of the series:", fib_sum(n))
module-এর function ডাকা: fibo.fib_series(n) এবং সরাসরি fib_sum(n)।

Exam Tip

খাতায় দুটি file আলাদা শিরোনাম দিয়ে লেখো (fibo.py ও main.py), আর উল্লেখ করো যে দুটি একই folder-এ রাখতে হবে। শুরুতে module-এর সংজ্ঞা ও import-এর syntax দিলে পূর্ণ নম্বর।

Package তৈরির ধাপগুলো উদাহরণসহ লেখ।
বই: 3.7★★☆

উত্তর

  • একটি folder তৈরি করো — folder-এর নামই package-এর নাম (যেমন school)।
  • folder-এর ভেতরে __init__.py নামে একটি file রাখো (ফাঁকা হলেও চলে) — এটি folder-কে package হিসেবে চেনায়।
  • folder-এ প্রয়োজনীয় module (student.py, result.py) রাখো।
  • folder-এর বাইরের file থেকে import package.module বা from package import module লিখে ব্যবহার করো।

Module, Package and Application Software

Program বড় হতে থাকলে একটা file-এ সব কোড রাখা অসম্ভব হয়ে যায় — হাজার লাইনের একটা file-এ কোনো function খুঁজে পাওয়াই কঠিন। সমাধান হলো কোডকে আলাদা আলাদা file-এ (module) ভাগ করা, আর সম্পর্কিত module-গুলো একটা folder-এ (package) সাজানো। এভাবেই বাস্তবের বড় software তৈরি হয়।

এই অধ্যায়ের শুরুতে দেখব application software কী, কত প্রকার আর কোথায় ব্যবহার হয়। তারপর module ও package-এর ধারণা, এদের গুরুত্ব, আর নিজের হাতে module ও package তৈরি করব।

3.1 Application Software কী?

কম্পিউটারের software মোটা দাগে দুই ধরনের। System software কম্পিউটার চালায় — operating system (Windows, Linux, Android), device driver, utility program। আর application software দিয়ে ব্যবহারকারী নিজের নির্দিষ্ট কাজ করে — চিঠি লেখা, হিসাব রাখা, ছবি সম্পাদনা, ভিডিও দেখা।

সংজ্ঞা (পরীক্ষার জন্য)

Application software হলো এমন software, যা ব্যবহারকারীর নির্দিষ্ট কোনো কাজ বা সমস্যা সমাধানের জন্য তৈরি করা হয়। এটি system software-এর (operating system) উপর চলে এবং সরাসরি ব্যবহারকারীর প্রয়োজন মেটায়। যেমন: Microsoft Word, Excel, web browser, accounting software।

বাস্তব উদাহরণ

একটা বাড়ির কথা ভাবো। বিদ্যুৎ সংযোগ, পানির লাইন, দেয়াল — এগুলো ছাড়া বাড়ি চলে না, কিন্তু এগুলো নিয়ে তুমি সরাসরি কাজ করো না: এরা system software। আর টিভি, ফ্রিজ, রাইস কুকার — এগুলো দিয়ে তুমি নিজের কাজ করো, এবং এরা চলে বিদ্যুৎ সংযোগের উপর: এরা application software।

  • General Purpose Application Software: অনেক ধরনের ব্যবহারকারী অনেক ধরনের কাজে ব্যবহার করে। বাজারে তৈরি অবস্থায় পাওয়া যায়।

সংজ্ঞা (পরীক্ষার জন্য)

Module হলো Python কোড ধারণকারী একটি .py file, যার ভেতরে function, class ও variable থাকে এবং যা অন্য program-এ import করে ব্যবহার করা যায়। যেমন: math, random, datetime বা নিজের তৈরি geometry.py।

Package হলো সম্পর্কিত module-গুলোর একটি folder (directory), যার ভেতরে সাধারণত __init__.py নামে একটি বিশেষ file থাকে। Package দিয়ে অনেকগুলো module সুশৃঙ্খলভাবে সাজানো হয়।

বাস্তব উদাহরণ

একটা লাইব্রেরির কথা ভাবো। প্রতিটা বই একটা module — একটা নির্দিষ্ট বিষয়ে লেখা। একই বিষয়ের বইগুলো একটা তাকে (shelf) রাখা: সেই তাকটা একটা package। আর পুরো লাইব্রেরি হলো library — অনেকগুলো package-এর সংগ্রহ।

বিষয়ModulePackageLibrary
কীএকটা .py filemodule-এর folderpackage/module-এর বড় সংগ্রহ
চেনার উপায়.py extensionfolder + __init__.pyসাধারণত pip দিয়ে install
উদাহরণmath, random, geometry.pyschool/, os, emailNumPy, Django, pandas

3.5 Module ও Package-এর গুরুত্ব

  1. কোড পুনর্ব্যবহার (Reusability): একবার লেখা module যেকোনো program-এ import করে ব্যবহার করা যায় — একই function বারবার লিখতে হয় না।
  2. সুশৃঙ্খল কাঠামো (Organization): বড় program যুক্তিসঙ্গত ছোট ছোট file আর folder-এ ভাগ হয়, ফলে কোড খুঁজে পাওয়া ও বোঝা সহজ।
  3. নামের সংঘর্ষ এড়ানো (Namespace): দুটো module-এ একই নামের function থাকলেও সমস্যা নেই — student.show() আর teacher.show() আলাদা।
  4. সহজ রক্ষণাবেক্ষণ (Maintenance): ভুল ঠিক করতে বা নিয়ম বদলাতে শুধু সংশ্লিষ্ট module-এ হাত দিলেই হয়।
  5. দলগত কাজ (Team Work): একেকজন programmer একেকটা module-এ কাজ করতে পারে।
  6. শেয়ার করা সহজ: package বানিয়ে অন্যদের দেওয়া যায়। হাজার হাজার package pip install দিয়ে বিনামূল্যে পাওয়া যায় — Python-এর জনপ্রিয়তার একটা বড় কারণ এটাই।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • Module ও package-এর গুরুত্ব বর্ণনা করো। (4 নম্বর)

প্রতিটা পয়েন্টের শিরোনাম আর এক-দুই লাইনের ব্যাখ্যা লেখো; সাথে একটা ছোট import উদাহরণ দিলে ভালো।

def rectangle_area(length, width):
    return length * width

def triangle_area(base, height):
    return 0.5 * base * height
তিনটা function — এই module-এর মূল কাজ।
13–15
if __name__ == "__main__":
    print("Testing geometry module...")
    print(circle_area(1), rectangle_area(2, 3))
__name__ একটা বিশেষ variable। file সরাসরি চালালে (python geometry.py) এর মান হয় "__main__", তাই পরীক্ষার কোড চলে। কিন্তু অন্য file import করলে মান হয় "geometry", তাই এই block চলে না। এভাবে module নিজেই নিজেকে পরীক্ষা করতে পারে।
লাইন-বাই-লাইন ব্যাখ্যা
1
import geometry
Python প্রথমে main.py-র folder-এ geometry.py খোঁজে, পেয়ে যায়। import-এর সময় .py লিখতে হয় না।
2–3
from geometry import rectangle_area
import geometry as geo
একই module বিভিন্নভাবে import করা যায়।
5–8

print("Triangle area :", geo.triangle_area(10, 6))

সাধারণ ভুল

ভুল

ফল: ModuleNotFoundError: No module named 'geometry.py'; 'geometry' is not a package

সঠিক

import-এ file-এর নাম .py ছাড়া লিখতে হয়। .py দিলে Python ভাবে geometry নামে একটা package-এর ভেতরে py নামে module খুঁজছ।

মনে রাখো

Module-এর নাম কখনো built-in module-এর নামে দিও না (যেমন math.py, random.py) — তাহলে তোমার file আসল module-কে ঢেকে দেবে এবং অদ্ভুত error আসবে।

অনুশীলন

converter.py নামে একটা module বানাও, যাতে celsius_to_fahrenheit(), km_to_mile() আর taka_to_dollar(amount, rate) function থাকবে। main.py থেকে import করে তিনটাই ব্যবহার করো।

3.7 Package তৈরির Program

বাংলাএই টপিকের ভিডিও · মে ২০২২

Samaresh Hazra · YouTube-এ দেখো ↗

Package বানানোর ধাপ: (১) একটা folder বানাও, (২) তার ভেতরে __init__.py নামে একটা file রাখো (ফাঁকাও হতে পারে), (৩) folder-এ module file-গুলো রাখো। তারপর folder-এর বাইরে থেকে package.module লিখে import করা যায়।

উদাহরণ 3.3school Package তৈরি

সমস্যা: school নামে একটা package বানাও, যাতে student.py (ছাত্রের তথ্য) আর result.py (ফলাফল হিসাব) দুটো module থাকবে। main.py থেকে package ব্যবহার করে ফলাফল দেখাও।

লাইন-বাই-লাইন ব্যাখ্যা
1
def average(marks):
average() আর grade() — ফলাফল সংক্রান্ত সব function এক module-এ।
4–8
def grade(marks):
    if min(marks) < 40:
        return "F"
    avg = average(marks)
    return "A+" if avg >= 80 else "A" if avg >= 60 else "B"
grade() নিজের module-এর average() ব্যবহার করছে। দুই শর্তের এক লাইনের if-else-কে পরপর জুড়ে লেখা হয়েছে।
লাইন-বাই-লাইন ব্যাখ্যা
1

package import করলে তার __init__.py স্বয়ংক্রিয়ভাবে চলে। সেখানে INSTITUTE আর grade রাখা আছে, তাই school.INSTITUTE আর school.grade সরাসরি পাওয়া যাচ্ছে।
2

package থেকে একটা module import।
3
from school.result import average
package-এর module থেকে নির্দিষ্ট function import — dot দিয়ে folder → file → function।
6–7
rahim = student.make_student("Rahim", 101, [78, 85, 62])
student.show(rahim)
student module-এর function। ছাত্রের তথ্য একটা dictionary-তে রাখা হয়েছে; rahim["marks"] দিয়ে মার্কস পাওয়া যায়।

__init__.py-এর কাজ

__init__.py-এর লাইন 2-এ from .result import grade — এখানে dot মানে "এই একই package-এর ভেতরের"। একে relative import বলে। এর ফলে ব্যবহারকারী পুরো ঠিকানা (school.result.grade) না লিখে শুধু school.grade লিখতে পারছে। __init__.py এভাবে package-এর "সামনের দরজা" হিসেবে কাজ করে।

সাধারণ ভুল

ভুল

ফল: ImportError: cannot import name 'marksheet' from 'school' (school/__init__.py)

সঠিক

package-এ marksheet নামে কোনো module নেই। import-এ নামের বানান আর বড়-ছোট হাতের অক্ষর হুবহু folder-এর file-এর মতো হতে হবে।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • একটি package তৈরির ধাপ লেখো এবং program-এর সাহায্যে দেখাও। (5 নম্বর)
  • __init__.py file-এর কাজ কী?

উত্তরে প্রথমে folder-এর গঠন (চিত্র 3.2-এর মতো) আঁকো, তারপর প্রতিটা file-এর কোড আলাদা শিরোনামসহ লেখো, শেষে main.py আর তার output।

অনুশীলন

shop নামে একটা package বানাও, যাতে product.py (পণ্যের দাম ও VAT হিসাব) আর billing.py (মোট বিল ও discount) দুটো module থাকবে। main.py থেকে তিনটা পণ্যের বিল তৈরি করো।

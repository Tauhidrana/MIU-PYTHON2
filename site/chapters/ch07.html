Exception and Error Handling in Python

তোমার program যত ভালোই লেখো, বাস্তবে কিছু না কিছু ভুল হবেই: ব্যবহারকারী সংখ্যার জায়গায় নাম লিখবে, যে file পড়তে চাইছ সেটা থাকবে না, কেউ শূন্য দিয়ে ভাগ করতে বলবে। সাধারণ program এসব পরিস্থিতিতে একটা লাল error message দেখিয়ে সাথে সাথে বন্ধ হয়ে যায় — আর ব্যবহারকারী বুঝতেই পারে না কী হলো।

ভালো program ভুলের জন্য প্রস্তুত থাকে। এই অধ্যায়ে শিখব exception কী, Python-এর তৈরি exception কোনগুলো, কীভাবে নিজে exception তোলা যায়, আর try, except, else, finally দিয়ে কীভাবে error সামলে program-কে বন্ধ না করে চালু রাখা যায়।

7.1 Exception কী?

বাংলাএই টপিকের ভিডিও · অক্টোবর ২০২৫

Program-এ তিন ধরনের ভুল হতে পারে:

ধরনকখন ধরা পড়েউদাহরণ
Syntax Errorprogram চালানোর আগেই, Python কোড পড়ার সময়colon বাদ পড়া, bracket না মেলা
Exception (Runtime Error)program চলার সময়, নির্দিষ্ট লাইনে পৌঁছালেশূন্য দিয়ে ভাগ, নেই এমন file খোলা
Logical Errorকখনো নিজে থেকে ধরা পড়ে না — ফল ভুল আসেগড়ের সূত্রে ভুল, শর্তের ক্রম ভুল

সংজ্ঞা (পরীক্ষার জন্য)

Exception হলো program চলার সময় ঘটা এমন একটি অস্বাভাবিক ঘটনা, যা program-এর স্বাভাবিক প্রবাহ বাধাগ্রস্ত করে। কোনো exception ঘটলে Python একটি exception object তৈরি করে; সেটা সামলানো (handle) না হলে program থেমে যায় এবং একটি traceback দেখায়।

বাস্তব উদাহরণ

গাড়ি চালাতে গিয়ে চাকা পাংচার হলো — এটা একটা exception। গাড়ির ডিজাইন ঠিক ছিল (syntax error নয়), কিন্তু চলার পথে অপ্রত্যাশিত সমস্যা। ভালো চালক গাড়িতে স্পেয়ার চাকা রাখে, পাংচার হলে চাকা বদলে আবার চলে — এটাই exception handling। স্পেয়ার না থাকলে যাত্রা ওখানেই শেষ।

উদাহরণ 7.1একটি Exception এবং Traceback

সমস্যা: দুটো ভাগ করো, যার দ্বিতীয়টিতে ভাজক শূন্য। কী হয় দেখো।

লাইন-বাই-লাইন ব্যাখ্যা
1–2
print("Start")
print(10 / 2)
স্বাভাবিকভাবে চলল।
3
print(10 / 0)
শূন্য দিয়ে ভাগ — ZeroDivisionError। Program এখানেই থেমে গেল।
4
print("End")
"End" কখনো print হলো না। Exception সামলানো না হলে পরের সব লাইন বাদ পড়ে।

Traceback-এর শেষ লাইনটাই সবচেয়ে জরুরি: প্রথমে exception-এর নাম (ZeroDivisionError), তারপর কোলনের পরে কারণ (division by zero)। ভুল খুঁজতে সবসময় traceback নিচ থেকে পড়া শুরু করো।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • Syntax error, exception ও logical error-এর পার্থক্য লেখো।

Python-এ অনেকগুলো exception আগে থেকেই তৈরি করা আছে — এদের বলে built-in exception। সবচেয়ে বেশি যেগুলোর মুখোমুখি হবে:

Exceptionকখন ঘটেউদাহরণ কোড
ZeroDivisionErrorশূন্য দিয়ে ভাগ10 / 0
ValueErrortype ঠিক, কিন্তু মান অগ্রহণযোগ্যint("abc")
TypeErrorভুল type-এর উপর কাজ"5" + 3
NameErrorঅসংজ্ঞায়িত নাম ব্যবহারprint(totl)
IndexErrorlist-এর সীমার বাইরের index[1, 2][5]
KeyErrordictionary-তে নেই এমন key{"a": 1}["b"]
AttributeErrorobject-এ নেই এমন attribute/method"hi".push()

ModuleNotFoundErrorনেই এমন module importimport mathh

উদাহরণ 7.2একসাথে কয়েকটা Built-in Exception দেখা

সমস্যা: কয়েকটা ভুল কোড একটা একটা করে চালিয়ে কোনটা কোন exception দেয় দেখো।

লাইন-বাই-লাইন ব্যাখ্যা
1–8
tests = [
    "10 / 0",
    "int('abc')",
    "'5' + 3",
    "[1, 2][5]",
    "{'a': 1}['b']",
    "'hi'.push()",
]
ভুল কোডগুলো string আকারে একটা list-এ।
11
        eval(t)
eval() একটা string-কে Python expression হিসেবে চালায় — এখানে শুধু প্রদর্শনের জন্য ব্যবহার করেছি। সাধারণ program-এ eval এড়িয়ে চলো।
12–13
    except Exception as e:
        print(f"{t:<15} -> {type(e).__name__}: {e}")
exception ধরে তার class-এর নাম আর বার্তা দেখানো। try-except নিয়ে বিস্তারিত 7.4-এ।

Exception-এর পারিবারিক গাছ (Hierarchy)

সব exception আসলে class, এবং তারা inheritance-এর একটা গাছে সাজানো। এর ব্যবহারিক মানে হলো: parent exception ধরলে তার সব child-ও ধরা পড়ে।

তাই except LookupError লিখলে IndexError আর KeyError দুটোই ধরা পড়বে, আর except Exception প্রায় সব সাধারণ exception ধরবে।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • Python-এর পাঁচটি built-in exception উদাহরণসহ উল্লেখ করো। (3-4 নম্বর)

টেবিল আকারে exception-এর নাম, কখন ঘটে আর এক লাইনের উদাহরণ কোড লেখো।

7.3 Exception Raise করা

Python নিজে থেকে exception তোলে যখন কোনো কাজ অসম্ভব হয়। কিন্তু অনেক সময় কাজটা Python-এর কাছে বৈধ, অথচ আমাদের নিয়মে অবৈধ — যেমন মার্কস -20 বা 150। Python এতে আপত্তি করবে না। তখন আমরা নিজেরাই raise keyword দিয়ে exception তুলি।

Syntax

উদাহরণ 7.3মার্কস যাচাই

সমস্যা: একটা function লেখো, যেটা মার্কস 0 থেকে 100-এর বাইরে হলে ValueError আর সংখ্যা না হলে TypeError raise করবে।

লাইন-বাই-লাইন ব্যাখ্যা
2
    if not isinstance(marks, (int, float)):
isinstance(x, (int, float)) পরীক্ষা করে x int বা float কিনা।
4–5
    if marks < 0 or marks > 100:
        raise ValueError(f"Marks must be 0-100, got {marks}")
Python-এর কাছে 150 একদম বৈধ সংখ্যা, কিন্তু আমাদের নিয়মে অবৈধ — তাই নিজেরাই raise করলাম, স্পষ্ট বার্তাসহ।
9
print(set_marks(150))
raise হওয়া মাত্র function থেমে গেল, return পর্যন্ত পৌঁছায়নি।

নিজের Exception Class

Exception যেহেতু class, তাই Exception থেকে inherit করে নিজের exception বানানো যায়। এতে error-এর নাম দেখেই সমস্যা বোঝা যায়।

উদাহরণ 7.4Custom Exception

সমস্যা: ব্যাংক থেকে balance-এর বেশি টাকা তুলতে চাইলে InsufficientBalanceError raise করো।

লাইন-বাই-লাইন ব্যাখ্যা
1–2
class InsufficientBalanceError(Exception):
    pass
Exception থেকে inherit করা একটা ফাঁকা class-ই যথেষ্ট — নামটাই এর মূল পরিচয়।
5–7
    if amount > balance:
        raise InsufficientBalanceError(
            f"Balance {balance} Tk, requested {amount} Tk")
শর্ত পূরণ না হলে নিজের exception raise।
11–14
try:
    withdraw(5000, 8000)
except InsufficientBalanceError as e:
    print("Failed:", e)
এই exception-ও অন্য যেকোনো exception-এর মতো ধরা যায়। as e দিয়ে বার্তাটা পাওয়া যায়।

সঠিক

raise-এর পর শুধু string দেওয়া যায় না, একটা exception class বা object লাগে।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • Python-এ exception raise করার পদ্ধতি বর্ণনা করো। (3-4 নম্বর)
  • Custom exception কীভাবে তৈরি করা হয়?

অনুশীলন

set_age(age) function লেখো, যেটা বয়স ঋণাত্মক বা 120-এর বেশি হলে ValueError raise করবে। তারপর try-except দিয়ে তিনটা ভিন্ন বয়স পরীক্ষা করো।

7.4 try ও except Block

বাংলাএই টপিকের ভিডিও · সেপ্টেম্বর ২০২৬

try-except হলো exception সামলানোর মূল হাতিয়ার। যে কোডে exception হতে পারে সেটা try block-এ রাখো; exception হলে Python সাথে সাথে try ছেড়ে মিলে যাওয়া except block-এ চলে যায়, program বন্ধ হয় না।

Syntax

উদাহরণ 7.5ব্যবহারকারীর ভুল ইনপুট সামলানো

সমস্যা: ব্যবহারকারীর কাছ থেকে একটা সংখ্যা নাও; সংখ্যা না দিলে বন্ধ না হয়ে আবার চাও।

লাইন-বাই-লাইন ব্যাখ্যা
3
        n = int(input("Enter your roll: "))
int() সংখ্যা ছাড়া অন্য কিছু পেলে ValueError তোলে।
4
        break
exception না হলে তবেই এই লাইনে পৌঁছায় — loop থেকে বের হয়।
5–6
    except ValueError:
        print("Please enter digits only!")
ValueError হলে বার্তা দেখিয়ে loop আবার ঘোরে। ব্যবহারকারী তিনবার চেষ্টা করেছে, program একবারও বন্ধ হয়নি।

একাধিক except এবং as

উদাহরণ 7.6ভিন্ন exception, ভিন্ন সমাধান

সমস্যা: দুটো সংখ্যা নিয়ে ভাগ করো। সংখ্যা না দিলে এক বার্তা, শূন্য দিলে আরেক বার্তা।

লাইন-বাই-লাইন ব্যাখ্যা
7–8
    except ValueError:
        print("Error: please give numbers")
Python উপর থেকে except-গুলো মিলিয়ে দেখে, প্রথম যেটা মেলে শুধু সেটাই চলে।
9–10
    except ZeroDivisionError as e:
        print("Error:", e)
as e দিয়ে exception object পাওয়া যায়; print করলে Python-এর নিজের বার্তা আসে।
12–14
safe_divide("20", "4")
safe_divide("20", "abc")
safe_divide("20", "0")
তিনটা ক্ষেত্রে তিন রকম আচরণ, কিন্তু program একবারও থামেনি।

একই কাজে একাধিক exception ধরতে tuple ব্যবহার করা যায়: except (ValueError, TypeError):। আর সব ধরনের exception ধরতে except Exception as e: — তবে এটা শেষ except হিসেবে রাখো।

ভুল

ফল: Done

সঠিক

খালি except: আর pass মানে সব error চুপচাপ গিলে ফেলা — ভুল হলো কিনা কেউ জানতেই পারবে না, debugging দুঃস্বপ্ন হয়ে যাবে। সবসময় নির্দিষ্ট exception ধরো, আর অন্তত একটা বার্তা দাও।

সম্ভাব্য পরীক্ষার প্রশ্ন

  • try ও except block উদাহরণসহ ব্যাখ্যা করো। (4-5 নম্বর)
  • একাধিক except block কীভাবে কাজ করে?

অনুশীলন

একটা list [10, 20, 30] থেকে ব্যবহারকারীর দেওয়া index-এর মান দেখাও। সংখ্যা না দিলে ValueError, সীমার বাইরে হলে IndexError — দুটোই আলাদা বার্তা দিয়ে সামলাও।

try-except-এর সাথে আরও দুটো ঐচ্ছিক block যোগ করা যায়:

  • else: try block-এ কোনো exception না হলে চলে। সফল হলে যা করতে চাও, সেটা এখানে রাখো।
  • finally: exception হোক বা না হোক, সবসময় চলে — এমনকি return থাকলেও। File বন্ধ করা, connection ছেড়ে দেওয়ার মতো পরিষ্কারের কাজ এখানে রাখা হয়।

সমস্যা: একই function দুবার ডাকো — একবার সফলভাবে, একবার exception-সহ। কোন block কখন চলে দেখো।

লাইন-বাই-লাইন ব্যাখ্যা

    else:
        print("  else   : marks =", marks)

দুই ক্ষেত্রেই finally চলেছে।

Exam Tip

Exception handling-এর program-এ অন্তত দুটো আলাদা except, একটা else বা finally, আর সম্ভব হলে একটা raise রাখো। Output-এ সফল ও ব্যর্থ দুই ধরনের ক্ষেত্রই দেখাও।

অধ্যায়ের সারসংক্ষেপ

বিষয়মূল কথা
Exceptionচলার সময় ঘটা অস্বাভাবিক ঘটনা; সামলানো না হলে program থামে ও traceback দেখায়।
Built-inZeroDivisionError, ValueError, TypeError, NameError, IndexError, KeyError, FileNotFoundError ইত্যাদি; সব Exception class-এর বংশধর।
raiseনিজে exception তোলা: raise ValueError("বার্তা"); Exception থেকে inherit করে custom exception।
try-exceptঝুঁকিপূর্ণ কোড try-এ; মিলে যাওয়া প্রথম except চলে; as e দিয়ে বার্তা।
else / finallyelse: exception না হলে; finally: সবসময়, পরিষ্কারের কাজে।

File Operation in Python

এতক্ষণ যত program লিখেছি, সবগুলোর একটা বড় সমস্যা আছে: program বন্ধ হলেই সব data হারিয়ে যায়। একশো ছাত্রের মার্কস input দিলে, program শেষ হওয়া মাত্র সব শেষ — পরের দিন আবার প্রথম থেকে input দিতে হবে। কারণ variable-এর data থাকে RAM-এ, যা অস্থায়ী।

Data স্থায়ীভাবে রাখতে হলে সেটা hard disk বা SSD-তে file আকারে লিখতে হয়। এই অধ্যায়ে শিখব Python দিয়ে file খোলা, পড়া, লেখা আর বন্ধ করা — আর শেষে file ব্যবহার করে পূর্ণ কয়েকটা program।

2.1 File Operation কী?

সংজ্ঞা (পরীক্ষার জন্য)

File হলো storage device-এ (hard disk, SSD, pen drive) একটা নাম দিয়ে স্থায়ীভাবে সংরক্ষিত data-র সংগ্রহ। File operation বলতে program-এর মাধ্যমে file তৈরি করা, খোলা, পড়া, লেখা, data যোগ করা এবং বন্ধ করার কাজগুলোকে বোঝায়।

বাস্তব উদাহরণ

File হলো একটা খাতা। খাতায় কিছু লিখতে বা পড়তে হলে আগে খাতাটা খুলতে হয়, তারপর পড়ো বা লেখো, কাজ শেষে বন্ধ করে তাকে রাখো। খোলার সময় ঠিক করো শুধু পড়বে, নতুন করে লিখবে, নাকি আগের লেখার পরে যোগ করবে — এটাই file-এর "mode"।

File-এর প্রকারভেদ

ধরনকী থাকেউদাহরণ
Text fileমানুষ পড়তে পারে এমন লেখা, লাইন আকারে.txt, .csv, .py, .html
Binary file0 আর 1-এর আকারে data, সরাসরি পড়া যায় না.jpg, .mp3, .pdf, .exe

File Operation-এর তিনটি ধাপ

Python-এ file-এর নাম দেওয়ার দুই উপায়: relative path (যেমন "marks.txt" — program যে folder-এ চলছে সেখানে খোঁজে) আর absolute path (যেমন "D:/data/marks.txt" — পুরো ঠিকানা)। এই অধ্যায়ের সব উদাহরণে relative path ব্যবহার করা হয়েছে।

File খোলার সময় বলে দিতে হয় file-টা দিয়ে কী করবে। একে বলে mode। ভুল mode দিলে হয় error আসবে, নয়তো আরও খারাপ — আগের data মুছে যাবে।

Modeঅর্থFile না থাকলেFile থাকলে
rশুধু পড়া (default)FileNotFoundErrorশুরু থেকে পড়ে
wলেখানতুন file তৈরিআগের সব লেখা মুছে নতুন করে লেখে
aশেষে যোগ (append)নতুন file তৈরিআগের লেখা রেখে শেষে যোগ করে
xশুধু নতুন file তৈরিনতুন file তৈরিFileExistsError
r+পড়া ও লেখাFileNotFoundErrorশুরু থেকে পড়ে ও লেখে
w+লেখা ও পড়ানতুন file তৈরিআগের সব মুছে দেয়
a+যোগ ও পড়ানতুন file তৈরিলেখা সবসময় শেষে যোগ হয়

এর সাথে t (text, default) বা b (binary) যোগ করা যায়: যেমন "rb" মানে binary file পড়া (ছবি, PDF), "wb" মানে binary file লেখা।

উদাহরণ 2.1w আর a mode-এর পার্থক্য

সমস্যা: একই file-এ প্রথমে w mode-এ দুবার লেখো, তারপর a mode-এ লেখো — প্রতিবার file-এ কী থাকে দেখো।

f.write("Class starts at 9 AM\n")
f.close()
notice.txt তৈরি হলো, একটা লাইন লেখা হলো। \n মানে নতুন লাইন — write() নিজে থেকে লাইন ভাঙে না।
5–7
f = open("notice.txt", "w")
f.write("Class starts at 10 AM\n")

আবার w mode — আগের "9 AM" লাইন মুছে গেল, শুধু নতুন লাইন রইল।
8

file পড়ে দেখালাম: শুধু "10 AM"।
10–12
f = open("notice.txt", "a")
f.write("Lab on Thursday\n")
f.close()
a mode — আগের লেখা অক্ষত রেখে শেষে নতুন লাইন যোগ হলো।

উদাহরণ 2.2ভুল mode-এ যা ঘটে

সমস্যা: নেই এমন file r mode-এ আর আছে এমন file x mode-এ খোলার চেষ্টা করো।

লাইন-বাই-লাইন ব্যাখ্যা

    print("r mode: file does not exist")
try-except দিয়ে error ধরলাম, যাতে program বন্ধ না হয়ে বার্তা দেখায়। try-এর ভেতরে error হলে সংশ্লিষ্ট except-এ চলে আসে।
6–9
try:
    open("notice.txt", "x")
except FileExistsError:
    print("x mode: file already exists")
x mode ব্যবহার হয় যখন নিশ্চিত হতে চাও যে ভুল করে পুরনো file-এর উপর লিখছ না।

open() ও close()

Syntax

open() একটা file object return করে — এর মাধ্যমেই পড়া-লেখা হয়। encoding="utf-8" দিলে বাংলাসহ যেকোনো ভাষার লেখা ঠিকমতো সংরক্ষণ হয়।

close() কেন জরুরি? write() দিয়ে লেখা data সাথে সাথে disk-এ যায় না, প্রথমে memory-র একটা অস্থায়ী জায়গায় (buffer) জমা থাকে। close() ডাকলে তবেই সব data নিশ্চিতভাবে disk-এ লেখা হয় এবং file-টা অন্য program-এর জন্য মুক্ত হয়। close() ভুলে গেলে শেষের কিছু data হারিয়ে যেতে পারে।

সমস্যা: write() আর writelines() দিয়ে একটা ছাত্র তালিকা file-এ লেখো।

লাইন-বাই-লাইন ব্যাখ্যা

with open("students.txt", "w") as f:
প্রতিটা লাইনে নাম, রোল, মার্কস comma দিয়ে আলাদা — এই ধরনটাকে CSV (Comma Separated Values) বলে। Excel-ও এভাবে data খুলতে পারে।
2

write() লেখা character-এর সংখ্যা return করে — এখানে 13 (\n-ও একটা character)।

writelines() পুরো list একবারে লেখে। প্রতিটা string-এর শেষে \n নিজেকেই দিতে হয়েছে।

উপরে দেখানো হলো file-টার ভেতরে এখন কী আছে। এবার এটা চারভাবে পড়ি।

উদাহরণ 2.5পড়ার Function

সমস্যা: students.txt file-টা read(), read(n), readline(), readlines() আর for loop দিয়ে পড়ো।

লাইন-বাই-লাইন ব্যাখ্যা

প্রথম 10টা character। repr() দেখায় লেখাটা ঠিক কেমন, \n সহ।
3

read(10)-এর পর থেকে লাইনের বাকি অংশ। File object মনে রাখে কোথা পর্যন্ত পড়া হয়েছে — অনেকটা বইয়ের বুকমার্কের মতো।
4
    print(repr(f.readline()))
পরের পুরো লাইন।

readlines() সব লাইন list হিসেবে দেয়; প্রতিটার শেষে \n থাকে।

with open("students.txt") as f:

for loop-এ file সরাসরি দিলে লাইন ধরে পড়ে। strip() শেষের \n সরায়, split(",") comma দিয়ে ভেঙে list বানায়, তারপর তিনটা মান তিনটা variable-এ।

ভুল

সঠিক

a+যোগ ও পড়ানতুন file তৈরি করেলেখা সবসময় শেষে যোগ হয়


উত্তর
এর সাথে t (text, default) বা b (binary) যোগ করা যায়: যেমন "rb" দিয়ে ছবি বা PDF পড়া হয়, "wb" দিয়ে binary file লেখা হয়।




লাইন-বাই-লাইন ব্যাখ্যা
1–4
with open("notice.txt", "w") as f:
    f.write("Class at 9 AM\n")
with open("notice.txt", "w") as f:
    f.write("Class at 10 AM\n")
দ্বিতীয়বার w mode-এ খোলায় "9 AM" লাইন মুছে গেল, শুধু "10 AM" রইল।
5–6
with open("notice.txt", "a") as f:
    f.write("Lab on Thursday\n")
a mode আগের লেখা রেখে শেষে নতুন লাইন যোগ করল।
8–9
with open("notice.txt", "r") as f:
    print(f.read())
r mode-এ পড়ে ফলাফল দেখানো।
11–14
try:
    open("notice.txt", "x")
except FileExistsError:
    print("x mode: file already exists")
file থাকায় x mode-এ খুলতে গিয়ে FileExistsError।
